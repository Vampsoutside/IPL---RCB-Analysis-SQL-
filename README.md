# IPL – RCB Analysis SQL

A MySQL-based IPL analytics project focused on Royal Challengers Bangalore (RCB), using relational match, player, season, venue, toss, batting, bowling, wicket and ball-by-ball data.

## What this project covers

- RCB season performance and win trends
- Player batting and bowling analysis
- Player impact and team-performance relationships
- Home vs. away performance
- Toss-decision analysis
- Auction and retention strategy
- Ball-by-ball KPIs and performance metrics

## SQL techniques

The project uses multi-table JOINs, CTEs, subqueries, window functions, conditional aggregation, CASE expressions, GROUP BY/HAVING, ranking and derived KPIs.

## Database

The repository contains the SQL definitions/data for the IPL relational schema, including match, season, team, player, ball-by-ball, batting, bowling, wickets, extras, venues and related dimension tables.

> Player-specific findings and numerical conclusions should be taken from the executed query outputs rather than assumed from the schema alone.
